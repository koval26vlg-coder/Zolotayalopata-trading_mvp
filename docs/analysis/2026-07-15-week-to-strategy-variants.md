# Разбор вариантов: «рабочая стратегия за неделю» без смены бирж/монет

Дата: 2026-07-15
Метод: черновик плана (Claude Code) → адверсариальный red-team + операционный планировщик (2 независимых агента, workflow `wf_81138a5d-ff5`) → синтез. Research-only, не инвестсовет.
Ограничение пользователя: universe без изменений (MEXC/Gate, non-Binance). Ускорение — только во времени.

---

## 1. Честная рамка (главное, без прикрас)

**«Полностью рабочая стратегия за 7 дней» недостижима по построению собственной лестницы проекта** — и это защита, а не бюрократия: максимальный исторический вердикт = `ACCEPT_FOR_SHORT_EXECUTION_PROBE`, дальше обязателен paper-forward ≥15 наблюдений (при удержании 1–3 дня это 4–8 недель накопления). Обойти можно только ослаблением ворот — путь D ниже, отклонён.

**Достижимый максимум за 7 дней**: замороженный глубокий датасет + 2–3 честных вердикта + при удаче — ACCEPT, 20-минутный execution probe и ЗАПУЩЕННЫЙ paper-forward. Оценка вероятности ACCEPT на этой неделе: ~30–50% (база проекта 0/15, но впервые тест со статистической мощностью). Red-team потребовал назвать «неудачный успех» заранее: если все вердикты REJECT/INSUFFICIENT — неделя всё равно закрыта результатом (датасет + census + 3 честных вердикта), и это фиксируется сейчас, чтобы в пятницу не возникло давления на ворота.

Честный таймлайн: D7 — вердикты (± ACCEPT+probe+paper-старт); D14 — 5–8 paper-наблюдений из 15; **PAPER_READY медиана D35–60** (оптимистичный край D30 только при ≥5 событиях/нед); LIVE_REVIEW — за пределами месяца. Это самый быстрый честный путь, существующий физически.

## 3. План недели (Вариант A, скорректирован red-team + operator)

- **D1 (день, 3ч)**: батч одобрений пользователю одним пакетом (ночной слот D2 под бэкфилл; правило остановки OOS «max(60; до 20 событий; cap 100)»; хартия датасета). Внешний survivorship-чек: 10 заведомо делистнутых символов по архивам анонсов бирж → есть ли их klines в REST (30 мин, go/no-go). **Ветка провала фиксируется заранее**: survivorship >15% → окно сужается до 9 мес / стоп трека. Заморозка хартии: 4h основной (1h ВЫКИНУТ из первой волны — только для execution-модели позже), census-протокол без условных доходностей, эстиматор feasibility.
- **D2 (день)**: пробный сбор funding на 5 символах MEXC (глубина/пагинация) + проверка переменных funding-интервалов Gate — ДО полной ночи, чтобы ночь не ушла в брак. **D2 (ночь, после неприкосновенного PIT 23:00–23:20)**: полный REST-бэкфилл 4h+daily+funding × top-200 × 2 биржи. Ожидание: медианная глубина по символам реально 4–9 мес (многие листились <12 мес) — фиксируется честно в манифесте.
- **D3 (день)**: QC-чеклист (гэпы, редоминации 1000X-тикеров, переименования, funding-интервалы, конвенции open-time MEXC/Gate) → **только потом Merkle-freeze** (не ночью D2 — правка red-team) → feasibility-прогнозы. Census — только частоты/покрытие, ноль доходностей. Параллельно готовится paper-plan (operator: чтобы ACCEPT→probe+paper в один день).
- **D4 (день)**: заморозка 2 гипотез → OOS-оценки (секунды) → вердикты. **Слот №1 — гипотезе из банка, НЕ пере-регистрации v4** (правка red-team: v4 выбрана по наблюдённому результату, 199 старых дней лежат внутри бэкфилла, price-only PnL был отрицательным; пере-регистрация допустима только с письменным аргументом «что структурно меняет знак на 4h» и вердиктом на непересекающемся периоде — иначе это лотерея режима). Слот №3 — резерв.
- **D5**: при ACCEPT — execution probe (20 мин) + старт paper в тот же день; при REJECT/INSUFFICIENT — резервная гипотеза.
- **D6–7**: paper-сегменты; расчёт и публикация ожидаемой даты 15-го наблюдения (если >D45 — сказать сразу, не обнаружить на D30). Фон всю неделю: PIT-ночи 20 мин идут своим ходом, v6 feasibility — в очереди.

## 4. Предохранители, добавленные проверкой (обязательные)

1. Stress-гейт: множитель издержек ×1.5–2 (исторических спредов в klines нет — кост-модель нестационарна; ужесточение инвариантами разрешено).
2. Анти-фарминг слотов — правило вписывается СЕЙЧАС: новый датасет той же universe даёт свежие слоты только при существенной доле несмотренной информации (Merkle-diff) и не чаще раза в N месяцев.
3. Правило «подтверждённый дефект данных → новый Merkle без сжигания слотов» — определяется до инцидента, не после.
4. Walk-forward честность: при 2–4 событиях/нед фолды содержат 4–7 событий — вердикты фолдов шумные; feasibility-прогноз обязан учитывать per-fold минимумы, а не только сумму.
5. P(ACCEPT) и сценарий «3 REJECT» вписаны в план письменно (см. §1).

## 5. Ответ на вопрос пользователя одной строкой

За неделю честно достижимы: глубокий датасет, 2–3 вердикта и — с вероятностью ~30–50% — принятая стратегия с запущенным paper-forward. Подтверждённо рабочая (paper ≥15 наблюдений) — медиана 5–8 недель от старта; быстрее — только ослаблением ворот, что производит стратегию, работающую до первого контакта с рынком.
