Модуль: `trading_mvp/src/execution_gate.py` (8 тестов OK). Артефакт: `exports/trading-mvp/analysis/execution_gate_v1_20260703_091623.json`.

## Главный вывод: проценты живут, абсолютные суммы упираются в ёмкость

При консервативной оценке (стресс-выход тейкером через полосу ±50bps) суммарный потолок портфеля из 9 кандидатов — **порядка $1.5–3K дохода в год** при ~$10–15K развёрнутого капитала. Это честная цена тонких рынков.

Две оговорки, которые меняют картину:

1. **Оценка ёмкости консервативна для maker-стратегии.** Maker-ордера добавляют ликвидность, а не съедают её; позицию можно набирать пассивно днями. Биндит именно сценарий стресс-выхода. Верхняя граница — объёмный лимит (0.5% оборота): для BEAT это $85K вместо $1.7K. Истина зависит от дисциплины выхода; для paper-forward брать консервативную.
2. **Масштаб достигается шириной, а не размером.** Кандидатов с funding ≥10%/год — 77. Портфель из 30–50 мелких позиций по консервативной ёмкости — уже $10–30K/год потенциала, с диверсификацией venue-риска. Это меняет требование к инфраструктуре: нужен портфельный менеджер позиций, а не одна пара.

## Следствия для веток

- **Carry (H2/H3) остаётся promising**, но целевая конструкция — портфельная (30–50 имён), не концентрированная. Экономика по-прежнему требует multiweek forward-подтверждения персистентности.
- RAVE — только G-конструкция (спот мёртв); BROCCOLIF3B — только G (спот $9 глубины).
- Приоритет кандидатов по совокупности: BEAT, SKYAI, B, M, EVAA (E) + RAVE, BROCCOLIF3B (G).

## Ограничения v1

- Один снапшот стакана (12:15 +03 2026-07-03); глубина меняется в разы внутри суток — в weekly forward стоит добавить снятие стаканов для усреднения.
