## Первая остановка сохранена

`history_gold_source_v7_20261007` остановился на первом адресе с
`The read operation timed out`. Его состояние осталось `STOPPED_INCOMPLETE`,
`retry_authorized=false`. Файлы `parent-completion.json`, `parent-failure.json`,
`parent-intent.json` и `parent-request-plan.json` сохраняют исходное доказательство.

В первоначальной реализации каждый обработанный запрос записывал receipt до
перехода к следующему. На диске остался только план; при точном совпадении
runtime и конкретной ошибки это связывает остановку с первым адресом.
Прогресс другого вида, иная ошибка, изменённый план или другой runtime
не допускают продолжения этим механизмом.

В новой фазе `history_gold_unattempted_v7_20261007` проверены только позиции
2–19 исходного списка. Первый адрес не повторялся. Новый runtime прошёл тесты,
предварительную проверку родительских хэшей и видимый запуск с одним writer.
Фаза завершилась `COMPLETE`: все оставшиеся адреса получили результат проверки,
но это не означает успешную загрузку рыночных данных.

Общий предел сохранён: первоначальная фаза заняла около 10,9 секунды; её
продолжение разрешалось только при длительности родителя до 60 секунд и имело
предел 240 секунд. Время работы двух фаз не могло превысить 300 секунд.
Предел каждого ответа 1 MB, общий резерв всех 19 адресов 19 MB. Нового расписания
или постоянного сборщика нет. Никаких прокси, перенаправлений или повторов.

## Что изменено в коде

`gold_history.py` проверяет LZMA-контейнер и 20-байтовые записи, явный UTC-час,
порядок времени, положительные цены, bid/ask и конечные неотрицательные размеры.
Сохраняются исходные целые значения цены. Масштаб не подбирается по правдоподобию,
валюта цены и единицы объёма не объявляются доказанными.

Диагностическое объединение четырёх часов возможно только при наличии всех
четырёх файлов с данными. Оно не создаёт evaluator input и не доказывает
непрерывность исторического потока. Котировки с одинаковым временем сохраняются;
пустой файл не становится свидетельством закрытой сессии.

Исправлена обработка остановок: сетевой таймаут фиксируется для одного источника,
но явная команда остановки или общий дедлайн прерывает работу. Перед каждым
запросом теперь сохраняется запись попытки. Это не разрешение повторять старые
запросы. В JSON-отчёт unit-тестов добавлены подробности ошибок.

Первый запуск 151 теста выявил слишком узкое ожидание типа исключения:
повреждённый файл корректно отвергался, но тест ожидал только ошибку декодера,
а не ошибку неполного контейнера. Ожидание исправлено без ослабления проверки.
**Итог: 154 теста прошли, ошибок и падений нет.** Пройдены тесты пакета,
не весь legacy-проект. Реальный парсер архивов ещё не проверен на данных
Dukascopy, поскольку ни один архив не загрузился.

## Источники и ограничения

- [Публичный экспорт Dukascopy](https://www.dukascopy.com/api/data/get/historical-data-export)
  описывает загрузку исторических котировок. Это не сертификат полноты файлов.
- [Торговые условия](https://www.dukascopy.com/swiss/english/forex/forex-trading-accounts/link/)
  указывают дневные перерывы, летнее/зимнее время и праздничные исключения.
  Текущая страница не использована для выдуманного календаря 2023–2026.
- [Размеры ордеров](https://www.dukascopy.com/wiki/en/development/strategy-api/orders-and-positions/order-amounts/)
  описывают количество золота в унциях. Они не устанавливают исторический
  масштаб целых значений в файле, комиссии и даты действия условий.
- [Документация массового экспорта](https://www.dukascopy.com/wiki/en/development/data-export/)
  требует AWS credentials и оплату requester-pays. Этот путь не использован.

Публичные документы о формате были прочитаны отдельно от 19 запросов к источникам.
Ни найденный пример декодера, ни сегодняшняя спецификация не подменяют исторические
условия. Все проверки остаются исследовательскими, без реальных операций.

## Следующий ограниченный шаг

Generic ASCII ticks с bid/ask. Время фиксированное EST, UTC−5, без летнего сдвига.
Это другой кандидат, не уже проверенный вход. Его архивы в данном этапе
не скачивались и полнота 2023–2026 не подтверждена.

Далее: проверить один небольшой заранее выбранный файл HistData, происхождение
цен и правила времени, затем оценить календарь и расходы. Не повторять текущие
неуспешные адреса Dukascopy. Если альтернативный источник также непригоден,
завершить ограниченный поиск по золоту с указанием пробелов и перейти к очереди,
а не включать платные источники или длительный сбор.
