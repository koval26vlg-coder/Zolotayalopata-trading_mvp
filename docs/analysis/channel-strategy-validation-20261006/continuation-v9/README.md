## Реализация и контроль

Добавлен `histdata_month.py` и стадия `histdata-month` видимого launcher.
Чтение потоковое, максимальный размер распаковки 256 MiB, не более 4 млн строк,
жёсткий лимит 600 секунд. Исходный ZIP привязан к успешному аудиту v8 и проверяется
по SHA256 до и после прохода. Изменение данных при прежнем числе строк не допускается.

Каждая порция хранит SHA256 сырых строк, диапазоны строк и байтов, начальное и
конечное время, хэш предыдущей порции и привязку к входным данным и коду.
Итоговый файл создаётся только после полного EOF, проверки CRC всех членов ZIP,
точного числа строк, размера CSV и непрерывности цепочки. Частичные порции сами
по себе не дают статуса готовности. Из старых `STOPPED_INCOMPLETE` ничего не переписано.

Новые тесты проверяют некорректный хвост, пересечённые цены, нарушение времени на
границе порций, CRC дополнительного TXT, лимиты, остановку, пропуск и перестановку
порций, а также детерминированность. Сначала 7 новых тестов ожидаемо упали из-за
отсутствия реализации; затем все 180 тестов прошли. Обе записи сохранены.
Это тесты данного пакета, не всего legacy-проекта.

Видимый запуск `history_histdata_month_v9_20261007` прошёл в одном процессе.
Прерывание ответа Codex не вызвало повторного запуска: завершение проверено по
локальному `completion.json`. Global writer освобождён. Окно этого завершённого
прогона теперь можно закрыть.

## Что ещё не доказано

Статус входа модели остаётся **`BLOCKED_DATA`**, а не отрицательный вердикт стратегии.
Не проверены исторический календарь, источник исполнимых цен и тип контракта,
единицы и комиссии, покрытие всего периода 2023–2026. Отсутствуют готовые входы evaluator.
133 наблюдаемых 4h-интервала не равны 133 доказанным полным свечам и недостаточны
даже для 220 завершённых баров прогрева EMA220. Из этого месяца нельзя честно
получить результат всей замороженной программы.

Сделки, PnL, OOS и оценка прибыльности не выполнялись. Все 20 моделей остаются
в реестре с прежними хэшами. Listing Momentum и старые закрытые ветки не затронуты.
