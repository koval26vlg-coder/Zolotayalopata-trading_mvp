## Сводка

- 20 моделей: нет готового проверенного входа.
- Для 16 моделей есть ограниченные проверки источников; для 4 (№7–10) отдельный аудит ещё не выполнен.
- На пригодных исторических входах оценено: 0. Кандидатов: 0. Отрицательных торговых вердиктов этой программы: 0.
- Параметры, периоды и семейство Holm=20 не менялись. BLOCKED_DATA не уменьшает семейство тестов.
- Проверка совместимости общих критериев со всеми моделями ещё не завершена; пока отдельно подтверждён конфликт Aave.
