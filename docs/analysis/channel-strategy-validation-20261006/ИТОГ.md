## Что уже проверено

- Экстремум нельзя использовать раньше двух подтверждающих баров.
- Вход не совершается по ещё неизвестной свече; задержанные старые бары также не используются раньше публикации.
- При неопределённом порядке внутри свечи первым считается стоп; gap может ухудшить выход.
- Удалённый актив не исчезает задним числом из старого universe.
- Комиссии обеих ног, реальный момент funding и contract multipliers учитываются отдельно.
- Незакрытый grid или непродаваемый токен не выдаются за завершённую прибыльную сделку.
- Будущая прибыль не финансирует новые позиции; общий денежный бюджет ограничен.
- Изменение данных при том же числе строк и изменение кода инвалидируют прежний результат.
- Отчёт может формироваться без повторного расчёта сделок.
- Поправка Holm сохраняет 20 исходных гипотез, включая заблокированные.

## Что делать дальше

**Первый практический шаг: подготовить полный PIT набор Gate для моделей 1-4.**
Не заменять точный quote-turnover оценкой `base_volume * close` и не выбирать сегодняшний топ монет.
Затем выполнить один замороженный исторический расчёт, без перебора параметров.
Grid требует дополнительного book-набора, поэтому не выдаётся за готовый свечной backtest.

Для остальных направлений сначала собрать готовые бесплатные исторические файлы и проверить
входной контракт. Где пригодной истории не удаётся получить, сохранить `BLOCKED_DATA`,
не запускать постоянный collector и не ждать новые события.

Независимость финальной истории пока не подтверждена. Даже будущий положительный предварительный
расчёт не станет автоматически независимым OOS или разрешением торговать.

Старые отрицательные вердикты, Listing Momentum и paused premarket-depth оставлены без изменений.
Новых расписаний, private API, реальных ордеров и платных источников нет.
