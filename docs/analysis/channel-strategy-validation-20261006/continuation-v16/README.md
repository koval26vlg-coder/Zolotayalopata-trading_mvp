# Парные модели: исторический состав и архивы Gate

8 октября 2026. Продолжение отдельной программы 20 моделей. Торговый план,
параметры, расходы, риск и критерии отбора не изменены.

## Выполнено

- Исправлен пропуск проверки месячного исторического состава в моделях 7-10.
  Без наблюдаемого актуального списка расчёт блокируется; исключённый актив
  не открывает позицию. Проверка выполняется на сигнале и на входе, в том
  числе при смене месяца. Уже открытой позиции разрешено закрыться.
- Стадии inventory/validate требуют `pit_universe` для парных моделей.
  Это применение общего правила старого плана, а не новая конфигурация сигнала.
- Семь новых regression-тестов сначала воспроизвели дефект; после исправления
  прошли. Ещё четыре теста проверяют ограниченную загрузку, gzip и отсутствие
  повторов/переходов. Полный видимый прогон: **191 тест, 0 ошибок**.
- Выполнен один видимый public read-only probe: BTC_USDT, январь 2023 и январь
  2025, по пять типов файлов. Все 10 запросов получили HTTP 200.
- Скачано **4 354 632 байта**, без retries, redirects, private API или новых
  расписаний. Все файлы изолированы от входов evaluator.

## Что Обнаружено

| Архив | Результат |
|---|---|
| Spot/perp стаканы, четыре часовых файла | Сжатые ответы получены целиком, но распаковка проверена только в пределах 1 МБ на файл; целостность полных gzip ещё не подтверждена |
| Фактические funding-выплаты, два месячных файла | Полные gzip проверены; по 93 строки, два CSV-поля. Это ещё не сертификат времени выплат и единиц |
| Прогнозные funding-обновления, два файла | Сжатые ответы полные; проверены только префиксы распаковки. В образце восемь CSV-полей |
| Mark prices, два файла | Получено только по 1 МБ сжатого префикса; объявленный размер 2 974 328 и 16 998 886 байт. Полнота не заявляется |

В spot-образцах `current`/`update` похожи на миллисекунды, в perp-образцах
на секунды с дробной частью. В spot уровни представлены парами цена/количество,
в perp объектами `p`/`s`. Это наблюдения по образцам, не подтверждение единиц
контрактного размера или причинно доступного времени. `sample_csv_widths`
для JSON-стаканов не является схемой: это лишь диагностическое разбиение превью.
Основание выбора URL: [официальное описание архивов Gate](https://www.gate.com/developer/historical_quotes).

## Честный Статус

Пропуск PIT-проверки исправлен. Пригодный полный вход для моделей 7-10 пока
не собран: нет проверенного исторического universe, полной синхронной истории,
датированных расходов и единиц контрактов. Для MEXC многолетние исполнимые
котировки по-прежнему не подтверждены.

Все 20 моделей остаются `BLOCKED_DATA`: это **не отрицательный результат
стратегий**. Бэктест, OOS и расчёт доходности на реальных данных не запускались.
Старые отчёты сохранены как исторические доказательства; их проверки старого
runtime нельзя использовать для сертификации исправленного кода.

## Следующий Шаг

Без сети разобрать уже скачанные полные spot/perp gzip и funding-выплаты:
потоково проверить CRC/полноту, формат времени, порядок и дубли, диапазон часа,
реальную глубину и семантику размеров. Подготовить нормализованные диагностические
образцы с явными пробелами, но не допускать их к evaluator до проверки всех
зависимостей. Не повторять десять запросов и не достраивать неполные mark-файлы
догадками. Затем принять одно решение о пригодности этого источника, прежде чем
расширять загрузку. Торговые пороги не подбирать.
