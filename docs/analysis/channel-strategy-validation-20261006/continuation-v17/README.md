## Диагностические Образцы

Для каждого файла сохранены первые две и последняя допустимая запись с номером
строки и хэшем исходного файла. Время приведено к целым микросекундам: spot из
миллисекунд, perp и funding из секунд. Сохранены исходные размеры уровней.

Образцы **не являются входом evaluator**. У них нет выдуманного `available_at`,
нет подтверждения множителя контракта, пересчёта perp-size в количество монет
или исторических комиссий. Период funding в восемь часов установлен только
для этих двух файлов, не распространён на другие активы или даты.

## Решение По Источнику

**Архивы полезны для дальнейшего локального разбора, но пока не допущены к бэктесту.**

Причины: перестановки и повторы spot, серверные ошибки внутри архива, неизвестное
время реальной доступности снимков, неподтверждённые размеры контрактов и расходы.
Дополнительно отсутствуют полный исторический состав монет и покрытие всех
фиксированных периодов. Два часовых примера не доказывают качество многолетней истории.

Новые массовые загрузки пока не нужны. Следующий технический шаг: на этих же
файлах проверить причинное объединение spot/perp без сортировки задним числом,
с явным учётом пропусков, повторов и возраста котировок. После этого отдельно
решить вопрос исторических единиц, расходов и PIT-состава. Не снижать критерии
или менять торговый сигнал ради получения результата.

Все 20 моделей новой программы остаются `BLOCKED_DATA`. Бэктест/OOS/PnL не
запускались; отрицательных торговых вердиктов на основании этого аудита нет.
Частичные mark-price файлы и прогнозные funding-файлы не обрабатывались.

Проверки реализации: **200 тестов, 0 ошибок**, включая девять новых проверок
CRC/обрыва, лимитов распаковки, времени, дублей и детерминированности.
Listing Momentum, premarket, старые результаты и расписания не изменены.
