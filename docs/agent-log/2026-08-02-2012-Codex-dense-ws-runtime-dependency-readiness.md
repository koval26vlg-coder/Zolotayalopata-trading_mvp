# Dense WS: проверка деталей запуска

## Что нашли

Перед сбором программа сначала составляет список монет. Для этого она использует несколько дополнительных локальных файлов и библиотек Python. Эти детали раньше не были отдельно закреплены точными хешами.

Простыми словами: основной маршрут был опечатан, но перед входом в него оставалась маленькая непроверенная дверь.

## Что исправили

- Создан неизменяемый список всех нужных файлов, Python-библиотек и сертификатов.
- Создана проверка, которая сравнивает каждый файл с этим списком.
- Проверка встроена только во внешний шлюз запуска.
- Если хотя бы один файл изменится, запуск остановится до начала сборщика.
- Замороженный PlanOnly, длительность, сборщик, площадки, список монет, сигнал, расходы и риск не менялись.

## Что проверили

- Проверка зависимостей: `11/11 PASS`.
- Проверка шлюза запуска: `11/11 PASS`.
- Тесты замороженного контракта кампании: `24/24 PASS`.
- Точный `PreflightOnly`: разрешение найдено, зависимости `READY`, запуск сейчас `NOT_DUE`.
- Сеть, сборщик и writer не запускались; рыночные строки, returns, PnL и OOS не читались.

## Текущее состояние

Кампания готова к своему утвержденному окну. Сейчас запуск не выполнялся. В момент окна шлюз еще раз повторит всю проверку и закроется сам, если обнаружит любое отличие.
