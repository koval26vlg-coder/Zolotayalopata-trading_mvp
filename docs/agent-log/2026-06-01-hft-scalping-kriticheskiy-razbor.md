# Запрос
Подготовить критический разбор текста о микроструктурном скальпинге/HFT после проверки первоисточников канала, оформить source packet и двухслойную верификацию (внутриканально + внешние первичные источники).

# Результат
Создан документ:
- `docs/analysis/2026-06-01-hft-scalping-kriticheskiy-razbor.md`

В документе:
- карточки 3 целевых выпусков канала (дата, гость, ключевые таймкоды, формулировки);
- таблица верификации ключевых тезисов исходного фрагмента с вердиктами (`подтвержден / частично / не подтвержден / маркетингово-искажен`);
- редакторские правки, список высокорисковых формулировок и итоговые ограничения для публикации;
- внешние первичные источники: CFTC, FINRA, CME, SEC, FCA, ESMA, NY Fed, QJE.

# Проверки
- Проверено покрытие ключевых тезисов исходного фрагмента строками таблицы.
- Для спорных количественных заявлений (`до 90%`, `R:R 1:1`) явно указан статус доказанности и условия применимости.
- Для терминов `spoofing`, `iceberg`, `stop` использованы первичные регуляторные/биржевые материалы.

# Риски
- YouTube-расшифровки автогенерируемые (ASR), возможны неточности имен/словоформ.
- Часть выводов гостей имеет характер мнения/рыночного жаргона и не равна эмпирическому доказательству.
- Даты публикации видео взяты из открытых метаданных стороннего API-агрегатора; при необходимости можно дополнительно перепроверить через YouTube Data API.
